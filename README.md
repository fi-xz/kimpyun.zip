## 심각도 기준

| 등급         | 정의                                               |
| ------------ | -------------------------------------------------- |
| **Critical** | 접근성 실패. 일부 사용자가 사이트를 사용할 수 없음 |
| **High**     | 실제 고장이거나 명백한 마찰. 지금 사용자에게 보임  |
| **Medium**   | 유지보수 비용, 규약 이탈, 작은 불일치              |
| **Low**      | 폴리시, 엣지 케이스                                |

## 현재 상태 요약

리뷰 시점(커밋 `08cd938`) 기준 확인된 문제:

- 텍스트 대비 **7곳 미달** (최저 1.63:1, 기준 4.5:1)
- `:focus-visible` 선언 **0개** — 키보드 사용자에게 현재 위치가 보이지 않음
- `prefers-color-scheme` 대응 **0건**
- `rem` 사용 **0곳** — 폰트 크기 12개가 전부 `px`
- OG 이미지가 배포본에 **존재하지 않음** → 소셜 미리보기 깨짐
- 이미지 총 **658 KB**, 최대 1920×1920 원본을 20px로 렌더
- 단축 URL 설정이 저장소에 **없음** (Cloudflare 대시보드에만 존재)
- 면책 고지 6문단이 두 파일에 **완전 중복**

## 검증 명령

```sh
pnpm typecheck     # tsc --noEmit
pnpm build         # dist/ 생성
pnpm dev           # 로컬 확인
pnpm preview       # 빌드 산출물 확인 (주의: dev-404 미들웨어 미적용)
```

작업 후 반드시 `pnpm build`로 **`dist/` 산출물을 직접 열어 확인**하십시오.
01번 OG 버그는 소스만 봐서는 발견되지 않고 산출물에서만 드러납니다.
